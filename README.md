# ECS_ymod
ECS_ymod is a small lightweight ECS engine used to implement a very basic 2D game using SDL graphics libs. This project supports LUA scripting and USD for world description: the wrappers need to be completed/optimized but they are still able to read a USD file or a LUA script. Right now the output is a small Star chicken able to shoot projectiles against UFO enemies (very basic) with keyboard and mouse support. I also added sprite collisions and I started to implement projectile logic (not completed yet). 

Here is a recap of all the features:
- ECS engine
- SDL 2D graphics
- LUA support
- USD support
- Collisions
- Multithreading
- Access system (first pass stage, not completely integrated in the engine)
- Custom mouse pointer support
- keyboard/mouse support
